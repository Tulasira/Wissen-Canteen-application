# ECS Log Group Module

## Overview

This module creates a CloudWatch Log Group for ECS containers.

The log group stores application logs generated by containers running on AWS Fargate.

---

## Architecture Flow

```text
Container
    ↓
AWS Logs Driver
    ↓
CloudWatch Log Group
    ↓
Amazon CloudWatch
```

---

## Resources Created

- aws_cloudwatch_log_group

---

## Features

- Configurable retention period
- Environment-based naming
- Automatic log management
- Fargate compatible
- Common tagging strategy

---

## Inputs

| Name | Description |
|------|-------------|
| enabled | Enable or disable Log Group creation |
| project_name | Project name |
| environment | Environment name |
| retention_in_days | Log retention period |
| tags | Common tags |

---

## Outputs

| Name | Description |
|------|-------------|
| log_group_name | CloudWatch Log Group Name |
| log_group_arn | CloudWatch Log Group ARN |

---

## Example Usage

```hcl
module "ecs_log_group" {
  source = "../../modules/ecs/log-group"

  enabled      = true
  project_name = "vpc-alb-rds"
  environment  = "dev"

  retention_in_days = 7

  tags = local.common_tags
}
```

---

## Notes

- ECS containers send logs to this log group.
- Log retention can be configured using terraform.tfvars.
- AWS Logs Driver is used by Fargate tasks.
